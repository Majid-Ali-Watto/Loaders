A JavaScript loading spinner for any framework

			
circle-loader is a free, open-source loading spinner library with 50 circular CSS loaders. Show a loading overlay over the whole page or inside one element while data loads, with your own colors, size, speed, background and text. It has no dependencies, is safe with server-side rendering, and ships TypeScript types.

			
    
				
  • Works with React, Next.js, Vue, Nuxt, Angular, Svelte and plain JavaScript
    • 
				
  • Loader.wrap(promise) shows the loader and always closes it
    • 
				
  • Progress bar with a percentage for uploads
    • 
				
  • A <circle-loader> web component for declarative use
    • 
				
  • Accessible: announced to screen readers, keyboard focus stays out of the page behind it
    • 
				
  • Tree-shakable: about 6 KB gzipped with one spinner style
